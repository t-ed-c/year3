# Simulation and Modelling

## 📖 Course Overview
This course covers mathematical and computational modeling techniques used to simulate real-world systems, with emphasis on discrete event simulation and statistical analysis.

## 🎯 Learning Objectives
- Understand different types of simulation models
- Learn discrete event simulation techniques
- Apply Monte Carlo methods
- Validate and verify simulation models
- Analyze simulation output and draw conclusions

## 📚 Topics Covered
1. **Modeling Fundamentals**
   - System modeling concepts
   - Model classification
   - Modeling methodology

2. **Discrete Event Simulation**
   - Event-driven simulation
   - Queue theory applications
   - Simulation algorithms

3. **Monte Carlo Methods**
   - Random number generation
   - Statistical sampling
   - Variance reduction techniques

4. **Continuous Simulation**
   - Differential equations
   - Numerical methods
   - System dynamics

5. **Model Validation**
   - Verification techniques
   - Validation methods
   - Output analysis
