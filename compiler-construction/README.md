# Compiler Construction

## 📖 Course Overview
This course covers the theory and implementation of programming language compilers, including the phases of compilation and modern compiler design techniques.

## 🎯 Learning Objectives
- Understand the structure and phases of a compiler
- Implement lexical analyzers and parsers
- Design and implement semantic analyzers
- Generate intermediate and target code
- Optimize compiler output

## 📚 Topics Covered
1. **Lexical Analysis**
   - Regular expressions
   - Finite automata
   - Tokenization

2. **Syntax Analysis**
   - Context-free grammars
   - Top-down and bottom-up parsing
   - Parser generators

3. **Semantic Analysis**
   - Symbol tables
   - Type checking
   - Error handling

4. **Code Generation**
   - Intermediate code generation
   - Target code generation
   - Register allocation

5. **Optimization**
   - Local and global optimization
   - Data flow analysis
