# 3.2 Academic Year - Course Work Repository

This repository contains coursework and projects for the 3.2 academic year.

## 📚 Course Units

### 1. Compiler Construction
- **Folder**: `compiler-construction/`
- **Description**: Theory and implementation of programming language compilers
- **Topics**: Lexical analysis, parsing, semantic analysis, code generation

### 2. Multimedia Systems
- **Folder**: `multimedia-systems/`
- **Description**: Digital multimedia technologies and applications
- **Topics**: Audio/video processing, compression, multimedia databases

### 3. Simulation and Modelling
- **Folder**: `simulation-modelling/`
- **Description**: Mathematical and computational modeling techniques
- **Topics**: Discrete event simulation, Monte Carlo methods, system modeling

### 4. Research Methods in Computer Science
- **Folder**: `research-methods/`
- **Description**: Scientific research methodologies in computer science
- **Topics**: Literature review, experimental design, data analysis, academic writing

### 5. Mobile Application Programming
- **Folder**: `mobile-app-programming/`
- **Description**: Development of mobile applications for various platforms
- **Topics**: Android/iOS development, cross-platform frameworks, mobile UI/UX
